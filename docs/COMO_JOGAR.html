Como Jogar

Guia completo de mecânicas e progressão

🎯 Objetivo

Empurre todas as caixas até os alvos para completar cada fase. Cada mundo introduz uma nova mecânica — e cada mecânica exige um novo jeito de pensar. Ao terminar as fases normais de um mundo, enfrente o chefe em uma batalha de memória e reflexo.

🎮 Controles

  • W A S D ou ↑ ↓ ← → — mover o personagem
  • E — segurar / soltar bloco (arrastar caixas)
  • R — reiniciar a fase
  • Clique no canvas — mover 1 passo na direção do tile clicado
Modo Expert: em vez de teclas, você digita comandos de texto (mover direita, segurar bloco, etc.) para treinar raciocínio por comandos.

⚙️ Mecânicas

📦 Caixa

Empurre para o alvo. Você só pode empurrar — não puxar. Planeje antes de mover.

❄️ Gelo

Ao pisar ou empurrar uma caixa no gelo, ela desliza até sair do gelo ou bater em algo.

🌿 Vinhas

Uma caixa que entra em uma vinha fica presa. Empurre mais uma vez para soltar.

🚪 Botões e Portas

Pise no botão (ou empurre uma caixa até ele) para abrir a porta. Enquanto o botão estiver pressionado, a porta fica aberta.

💀 Chefe

Após a fase 3, enfrente o chefe. Memorize a sequência de blocos que ele mostra e pise neles na ordem certa.

🎚️ Dificuldades

🌿 Fácil

Fases curtas, menos puzzles. Ideal para aprender as mecânicas sem pressão.

⚔️ Normal

Complexidade crescente. Cada mundo exige domínio das suas mecânicas.

💀 Expert

Controle por comandos de texto. Ótimo para treinar raciocínio algorítmico.

Cada dificuldade tem seu próprio save isolado — completar o jogo no Fácil não desbloqueia fases no Normal.

📚 Academia de Código

A Academia ensina conceitos de programação conectando-os às mecânicas do jogo:

  • Variáveis → empurrar caixa (mudar posição)
  • Condições → paredes bloqueiam movimento (if/else)
  • Loops → gelo deslizante (while)
